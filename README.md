# I am in! — 100ª Comrades

Editor oficial de foto para a 100ª Comrades

## Publicar no GitHub Pages
1. Envie `index.html`, `manifest.json`, `sw.js` e `template-overlay.png` para a raiz do repositório.
2. GitHub → Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: `main` e folder `/ (root)`.
5. Salve e aguarde a publicação.

## Recursos
- Tela inicial de campanha com botões de galeria e câmera.
- Editor responsivo para celular e computador.
- Arrastar, zoom por controle e pinça no celular.
- Nome opcional.
- Download PNG em 1024×1536 ou 1080×1920.
- Compartilhamento nativo quando suportado.
- Processamento local; fotos não são enviadas para servidor.
- Service Worker com versão de cache atualizada.
